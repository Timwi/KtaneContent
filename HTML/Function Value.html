On the Subject of Function Value

Substitution under pressure.

  • When the needy module activates, it displays a function and a requested input.
  • Substitute the displayed input for x and evaluate the function.
  • Press the button containing the resulting value.
  • An incorrect answer records a strike and temporarily deactivates the module.
  • Failing to answer before the needy timer expires also records a strike.

Example

If the display shows f(x) = 2x + 3 and f(4) = ?, press 11.
