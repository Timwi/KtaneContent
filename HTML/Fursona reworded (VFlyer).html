On the Rewording of Fursona

Original Manual

  • On this module, there is an image of an anthropomorphic creature.
  • Starting from the top-left 3 sliders and going clockwise, the 6 sets of three sliders control the head color, eye color, and the colors of four other body parts, in that order.
  • Using the creature’s species in the table below as a row, identify the cell with the greatest number. In case of a tie, use the right-most cell of the tied. Correspond this cell in that column as the desired eye color.

Keys:
*I = lit indicators
!I = unlit indicators
B = batteries
BH = battery holders
P = ports
!P = empty port plates
S3 = third serial number character
S6 = sixth serial number character
*P = port plates
SL = number of letters in serial number
SN = number of numbers in serial number
MC = number of modules on bomb

Keep Talking and Nobody Explodes Mod Fursona
  • The desired creature’s head color is always complementary to its eye color.
    • Red is complementary to Cyan; Green is complementary to Magenta; Blue is complementary to Yellow.
  • The other four colors are assigned to the other four regions, so long as each of the mentioned colors have been used exactly once. If done correctly, the module will disarm. The module does not strike.
  • The sets of 3 sliders are in order of red, green, and blue channels. A reference of the slider states with that color is provided here:
