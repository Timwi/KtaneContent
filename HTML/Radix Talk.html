On the Subject of Radix Talk

74 in base 11 is 52. Oh wait, I wasn’t being specific enough.

This module has an unfinished sentence about base conversion in the format of “XXXXX converted to base XXXX is” with Xs representing digits in other bases/radixes. However, the main numbers may not be in base 10.

The subscript beneath the main numbers shows what base the number is in. This base is always written in decimal (base 10).

To solve the module, continue the sentence with the correct answer. The answer is determined by converting the original number in its said base to the radix shown in its said base. The radixes used will always be between base 210 and base 1610.

To submit an answer, type it on your keyboard and submit by pressing the enter key. If the submission is correct, the module will solve. Otherwise, the module will strike and reset with a new sentence.

For more information on bases and base conversion, refer to the Bases manual. Bases 1110 through 1610 use letters after digits, in alphabetical order.
