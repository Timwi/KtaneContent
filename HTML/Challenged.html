On the Subject of Challenged

People were bruteforcing Colored Squares during the Archipelago event... I guess players can do insane things when you give them such restrictions.

This module works exactly the same as Colored Squares, however the grid is smaller, and there are only 4 colors instead of 5. Also, the config table is random for each module, so you’ll need to figure out the configuration yourself. This module never strikes.
