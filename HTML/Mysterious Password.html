On the Subject of Mysterious Password

You can only access the mystery when no one is watching.

  • The buttons above each letter will cycle through the possibilities for that position.
  • Only one combination of the available letters will match a password below.
  • The module does not have a submit button. How must one submit then...

When the module is selected but the game is out of focus, the screens will each show a certain letter. These correspond to all of the possibilities for a certain column in another, mysterious password. This column is determined by the number of times the module has been defocused so far.

Because there are five positions, new letters will be shown for the first five times the game is out of focus and the module is selected. The buttons for the visible password may always be interacted with while the game is focused.

Once the module is selected and the game is defocused for the sixth time, the display will show a type of casing, along with a different buzzing sound. DO NOT FOCUS THE GAME AGAIN UNTIL YOU ARE READY TO INPUT AN ANSWER.

Take the position of the visible password’s solution in the grid on the next page. Using the column of the word in the grid, numbered 0 to 4 from left to right, shift the mysterious password’s solution to the left by that many letters. Then, using the row of the visible password’s solution, numbered from 0 to 25, Caesar shift the mysterious password that many letters forwards.

Once this is obtained, convert the word into a specific casing, depending on the module’s display.

  • UPPERCASE CONSISTS ENTIRELY OF CAPITAL LETTERS.
  • lowercase consists entirely of small letters.
  • Title Case Has the First Letter in Every Word Capital, With Some Exceptions. For Singular Words, Those Exceptions Do Not Apply.

Finally, copy this result to your clipboard, and focus the game again with the module selected. If the submitted word and casing is correct, the module will solve. Otherwise, it will strike. When a strike occurs, the visible password may change, but the mysterious password will stay the same. However, each position will again show their possibilities for the next five times the game is defocused, and submission will activate on the next time the game is defocused.
