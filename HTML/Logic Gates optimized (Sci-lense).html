Finding Gates

The defuser is given gates A, B, C and D, and gates E, F and G rely on those outputs.

To find gate E, F and G, add the indexes of gate A and B, C and E, and D and F, mod 6.

If there is found a duplicate gate while a duplicate gate has already been found, go down the list, wrapping to the top, until an unused gate is found.
