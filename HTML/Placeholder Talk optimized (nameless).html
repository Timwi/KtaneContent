On the Subject of Placeholder Talk

Wait, how many backslashes is that?

The module displays two phrases in the following format:

THE ANSWER [A]
[B]

[C]

To solve the module look up the values associated with the texts A/B/C, then submit (#strikes + A + B + C) % 4 + 1.

Two C phrases require adding/subtracting X to obtain the corresponding C value. In this case X is equal to the number of solved Placeholder Talk modules.
