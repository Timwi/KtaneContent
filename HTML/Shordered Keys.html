See Appendix ORDER for identifying modules in Ordered Keys family.

This module consists of 6 colored keys, each of which is labeled with a colored number, and a display that shows a yellow counter. All but a single key can be pressed in this state.

The possible colors for both the keys and the numbers labelling them are: (R)ed, (G)reen, (B)lue, (C)yan, (M)agenta, and (Y)ellow.

Any of the numbers 1 - 6 may appear on each of the keys.

Every time a module is solved, this module will reset and a new set of keys will be generated, forgetting values of any previous keys displayed.

The keys displayed will each have the values equal to the counter shown, unless the module resets.

One of the keys in that set will set the counter to 0, whose position equals the sum of the base-36 value of the Xth character of the serial number, the number of other solved Shordered Keys on the bomb, all modulo 6, plus 1, where X is the number displayed on the module. If that key that would set the counter to 0 is already pressed, the key to the right will, wrapping around to the first if the pressed key is 6th.

All following unpressed keys, after the mentioned key, will set the counter to a non-zero number, revealing other keys that are assigned to that number, except for the currently displayed number, and a hidden number.

Upon the counter being set to 0, a set consisting of previously generated keys will appear, alongside one key from the set whose value is that hidden number. Press these keys in ascending order of the values they originally have to disarm this module.

After pressing 6 keys in this state, if an incorrect key was pressed, the module will strike and reset.

Note: Exactly 36 keys on the module have been assigned values 1 to 6. While five of these keys are not shown, you will never see repeated keys with multiple different values via their combination of the labels and colors.
