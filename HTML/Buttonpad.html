Follow these rules in the order they are listed. Hold the correct button based on the first condition that applies:

  1. If there is a blue button with thesymbol on it, then hold that button.
  2. If exactly three of the buttons are the same color, hold the button with the unique color.
  3. If there is a white button and one of the buttons has asymbol on it, hold the bottom-right button.
  4. If there is a serial port and an indicator labeled BOB, hold any blue button. If none exist, hold the top-left button.
  5. If a button has thesymbol or thesymbol on it, hold any button that doesn’t have those symbols.
  6. If none of the buttons have thesymbol and there are no yellow buttons, hold any button with a unique color. If none exist, hold the top-right button.
  7. If exactly one button has thesymbol, thesymbol, or thesymbol, hold the button horizontally adjacent to it.
  8. If exactly one or three buttons have thesymbol, thesymbol, thesymbol, or thesymbol, hold the button vertically adjacent to the outlier.
  9. If none of the symbols in the above rules appeared, hold any button diametrically opposite to a button with a unique color. If none exist, hold the bottom-left button.
  10. If none of the rules apply, hold the top-left button.

The above only applies to the first button. The correct button to hold after the first one is the same as the LED that most recently turned on.

Releasing a Held Button

If you starting holding a button down, a different button’s LED will light up. Note down the color that lit up. Based on the color and label of the currently held button, you must release it at a specific time.

  • Use the two columns with the button’s color at the top.
  • Find the symbol on the button within both columns; only one of the symbols will appear in each column.
  • Take the number on the leftmost item in the two rows.
  • Sum these two numbers together, take the digital root, and release the button when this digit is displayed.
