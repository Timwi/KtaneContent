On the Subject of Octomino

Don’t let the path make you forget where the end is.

An octomino is a shape made of eight equal square cells connected edge-to-edge. Depending on the stage, the shape will be a 2D, 3D, or 4D octomino.

The buttons along the top of the module correspond to the cells’ colors. Once a stage begins, each button will be assigned a unique color.

Controls

  • Control buttons: The eight buttons along the top of the module. Use them to move across the octomino’s cells.
  • Reset button: Hold it for two seconds to reset the module. The reset function is only available while the timer is not running. This returns the module to Stage 1, resets the timer, and generates a new octomino puzzle. The button also displays the current stage progress (green inner sector) and information about the current stage’s offset (outer ring).
  • Rotation button: Located at the bottom-right. Use it to rotate the octomino.

The offset determines how many positions to count from the final button to find the start button.

  1. Locate the final button.
  2. Determine the counting direction from the button layout: If the leftmost button is above the horizontal midpoint of the button layout, count to the left. Otherwise, count to the right.
  3. Starting from the final button, move by the number of positions indicated by the offset. The button where you finish counting is the start button. If the count passes the end of the button layout, continue from the opposite end (wrap around).

Press the start button to begin the stage. All eight buttons will be assigned unique colors, and the button you pressed will become the current button.

Movement Rules

The color of the current button corresponds to the current cell on the octomino. You may press a button only if its corresponding cell is adjacent to the current cell. Diagonal contact does not count as adjacency. If any unvisited cells are adjacent to the current cell, you must press the button corresponding to the leftmost of those unvisited cells, based on the positions of the buttons along the top of the module. If no unvisited cells are adjacent to the current cell, you may press any button corresponding to an adjacent cell. A button is considered unvisited if it has not yet been pressed during the current stage.

Once every button has been pressed at least once, make sure the final cell is the current cell, then press its button again to complete the stage.

Stages

The green sector on the reset button indicates your progress through the stages. You have 90 seconds to complete all five stages. After each stage is completed, the elapsed time is halved.
