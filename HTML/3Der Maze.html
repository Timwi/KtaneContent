Keep Talking and Nobody Explodes Mod 3Der Maze

On the Subject of 3Der Maze

You are in a maze of twisty passages, all alike. Exits are to the north, south, east, west, top, and bottom.

  • The defuser starts in a random position and orientation in one of the ten mazes below.
  • Locate the defuser using a 3D view of the maze walls, which also shows the symbol inside the current space, and if there is a symbol in the space ahead.
  • The maze map is confined to a 4*4*4 cube and not cyclic.
  • One of the walls is the goal, the rest will cause strikes if moved into.
  • To defuse the module, locate the goal wall, and move through it from either side.
  • Using the methods below, calculate an x-coordinate (0–3), a y-coordinate (0–3), a z-coordinate (0-3), and a direction; the goal wall will be the first wall from these coordinates in the given direction.
  • The buttons, in reading order, do the following: turn upwards, turn downwards, roll anti-clockwise, turn left, move forward, turn right, roll clockwise.
  • Only the move forward button changes the location of the player.

x-coordinate:

  • Start with the first numeric digit in the serial number.
  • If greater than 3, subtract 4 until the number falls between 0-3 inclusive.

y-coordinate:

  • Start with the last numeric digit in the serial number.
  • If greater than 3, subtract 4 until the number falls between 0-3 inclusive.

z-coordinate:

  • Start with the number of batteries.
  • If greater than 3, subtract 4 until the number falls between 0-3 inclusive.

Direction:

  • Each maze contains three star icons marked on the map.
  • In each of these locations is a letter, which maps to the direction to the goal wall: “N” becomes North, “S” becomes South, “E” becomes East, “W” becomes West, “U” becomes Up, and “D” becomes Down.
  • Beware of direction letters not in these marked locations, they carry incorrect decoy instructions!

Disambiguation: The maps gets darker as they get further away from you.
