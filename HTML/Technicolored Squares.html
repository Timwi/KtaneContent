See Appendix SQUARE for identifying modules in Colored Squares family.

  • At the start, if there are not four colors that occur exactly twice each, you are looking at a different module.
  • Begin with the grid corresponding to the color that occurs eight times.
  • For each of the remaining eight squares in reading order, use its color and position to find the corresponding rule in that color’s table, then apply that rule to the bit grid.
  • For each pair of identically-colored squares, find both squares’ positions in the resulting bit grid.
  • Using the logic gate corresponding to the pair’s color, evaluate the two bits at those positions.
  • If the result is true, press the first square of the pair followed by the second. If the result is false, press them in the opposite order.
  • Repeat this for all four pairs to disarm the module.
