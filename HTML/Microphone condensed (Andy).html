MISINPUT! IT WAS A MISINPUT! CALM DOWN, YOU CALM THE F-

  • Start with initial volume (circled value) - RCA port count.
  • If there is a pop filter (black round thing) add 1.
  • If the value is negative multiply by -2.
  • If the result is greater than 5, use 0 instead.

The result is the deaf spot.

  1. If the LED is blinking, set the volume slider to 5 and turn on the alarm clock (or strike). Keep it on until the LED turns off. (This can take up to 10s.)
  2. Then set the volume to the deaf spot and press the LED.
  3. Turn on the alarm clock again.
