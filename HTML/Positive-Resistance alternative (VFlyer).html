There is a number on the module. Pressing the module will decrement this number. When this number is negative, pressing the status light will result in the module going into Reading State, showing many characters at once.

A timer of 180 seconds* will also start. Every two seconds, some number, X, will be added to A, where A is the 20-digit number in the middle of the module. X and A are in base-94*, and are both truncated to their 20* least significant digits.

Find a way to obtain X before the timer runs out, as the module enters submission upon running out of time. Alternatively, the status light can be pressed to enter submission prematurely.

Convert X from base-94 to base-36 and submit it via Tap Code using the following table, with rows first and columns second set of taps. Note that the module will show only the 7 last digits of the full submitted number.

After sending a digit, a timer of 2.5 seconds will start and the text will gradually turn red. If this timer runs out, the last inputted digit will be removed until there are no digits left.

To submit the inputted number, press the status light before time runs out. If the submitted number was correct, the module will solve. Otherwise, the module will fully reset. If no characters were inputted, the module will give a fake strike, otherwise a real one.

*Missions and settings may override this.
