О "Забудь цвета"

Когда это цвета и тригонометрия стали связаны?

Данный модуль состоит из двух дисплеев, шестерёнки со светодиодом и числом, двух неоновых ламп (нижний левый угол), трёх цветных цилиндров и ключа. Запишите всё, что показано на модуле, в начале бомбы и после каждого обезвреживания неигнорируемого модуля. Если фон модуля зелёный, перед вами "Forget Any Color".

Для каждого этапа:

  1. Используя таблицу, измените числа на неоновых лампах, пользуясь соответствующими им столбцами "Л" и "П", в зависимости от цвета каждого цилиндра слева направо. Не записывайте дробную часть, а также деления и взятия остатков от деления на 0. Возьмите последнюю цифру для значений обеих ламп.
  2. Внутри таблицы, начните на цвете светодиода шестерёнки. Двигайтесь вверх на новое значение левой лампы и двигайтесь вниз на новое значение правой лампы. Достигнув конца таблицы, продолжите с другой стороны таблицы.
  3. Создайте трёхзначное число, состоящее из левой лампы, правой лампы и последней цифры применения операции, соответствующей столбцу "Компонент бомбы" в строке из предыдущего шага, к сумме обоих ламп и числа шестерёнки.

    4. Вычислите синус этого трёхзначного числа и возьмите первые 5 чисел после запятой. Число может быть отрицательным. Запишите получившееся трёхзначное число ниже, чтобы получить первые 5 чисел после запятой его синуса:



    Вычислите модуль косинуса трёхзначного дисплея и возьмите первые 5 чисел после запятой. Это число должно быть положительным. Запишите трёхзначный дисплей ниже, чтобы получить первые 5 чисел после запятой его косинуса, взятого по модулю:


  4. Сумма этих чисел - число для данного этапа. Запомните его.
Цвет Л П Компонент бомбы
Красный (R) +5 -1 + кол-во батареек
Оранжевый (O) -1 -6 - кол-во портов
Жёлтый (Y) +3 +0 + последняя цифра серийного номера
Зелёный (G) +7 -4 - кол-во обезвреженных модулей
Циановый (C) -7 -5 + кол-во пластин для портов
Синий (B) +8 +9 - кол-во всех модулей
Фиолетовый (P) +5 -9 + кол-во держателей с батарейками
Розовый (I) -9 +4 - кол-во горящих индикаторов
Бордовый (M) +0 +7 + кол-во индикаторов
Белый (W) -3 +5 - кол-во негорящих индикаторов

Когда цилиндры станут серыми:

Просуммируйте числа всех этапов, беря только дробную часть.

Возьмите сумму по модулю, затем возьмите её обратный косинус. Для этого понадобится научный калькулятор. Округлите вниз данное значение, получив число от 0 до 90. Напишите сумму, взятую по модулю, ниже, чтобы получить её обратный косинус, округлённый вниз.

Введите результат при помощи неоновых ламп и поверните ключ для отправки ответа. При получении ошибки, вы можете просмотреть этапы с помощью ламп. Поверните ключ, чтобы вернуться к вводу. Если этапов не было, отправьте 90.
