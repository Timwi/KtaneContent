Votre texte d'intro doit aller ici.

Voici des modèles d'éléments communs de manuels. Faites attention à toujours fermer les balises (celles avec un /).

Listes à puces (Listes non-ordonnées)

  • Les puces doivent utiliser les balises <ul></ul>(groupe de puces) et <li></li>(une seule puce).
  • Vous pouvez avoir des puces imbriquées :
    • Puces
    • imbriquées (obtenue en imbriquant des uls dans un autre ul)
  • Ou des listes numérotées :
    1. Listes
    2. numérotées

Listes numérotées (Listes ordonnées)

  1. Les listes numérotées doivent utiliser les balises <ol></ol> et <li></li>.
  2. Les listes imbriquées marchent de la même manière (voir ci-dessus).

Texte

Utiliser des balises de paragraphe (<p></p>) pour des blocs de texte. De plus, pour le formatage du texte, utiliser :

  • Gras : <strong></strong> (HTML) ou font-weight: bold; (CSS).
    • Du texte en gras comme titre de tableau doit utiliser la balise <th></th>.
  • Soulignage : <em></em> (HTML) ou text-decoration: underline; (CSS).
  • Saut
    de ligne : <br> (HTML)

Dans la plupart du temps, les versions HTML de gras et de soulignage sont recommandées. Noter que le texte en italique n'est pas utilisé dans les manuels vanilla à part pour le texte d'intro et les références à des annexes et n'est donc pas inclus ci-dessus. Aussi, voici des exemples de titres :

Annexe M  Notes additionnelles

Voici d'autres choses à garder en tête en créant une page de manuel :

  • Il y a des commentaires /* ... */ dans le CSS dans les blocs <style> contenants des instructions. Suivre ces instructions avant de finir votre manuel.
  • Les modules normaux et demandants ont des manuels similaires. Les manuels pour des gadgets sont des annexes et formatées comme tels.
  • Chaque manuel ou annexe doit avoir <div class="page-footer... en bas de la page, mis à jour.
  • N'hésitez pas à demander de l'aide si besoin !
  • Quelques rappels :
    • N'oubliez jamais de fermer les balises (celles avec un /).
    • Dans la plupart du temps, les versions HTML du gras et soulignage sont recommandées.

Ce module paraît initialement vide mais devrait en réalité affiché un morceau de code HTML lorsqu'il est pressé. Peut-être plusieurs fois ? Heureusement cela devrait marcher, en garder simplement une trace. Il sonnera pour indiquer un appui. Lorsqu'il affiche le code HTML, utiliser le modèle de manuel pour y trouver le code HTML et appuyer dessus. Le nombre indique quel même code HTML doit être appuyé. Donc p1 veut dire de trouver le premier code de paragraphe dans le modèle de manuel et ul1li2 veut dire de trouver la première liste à puces et la seconde puce. Les balises table et div ne sont pas incluses. Cliquer sur le lien associé et cela devrait amener sur un autre manuel, puis en extraire une valeur en utilisant le tableau ci-dessous, puis la soumettre. Le nombre d'appuis avant que le code HTML ne s'affiche et la couleur de l'écran (montrée lors de la saisie) sont des modificateurs.

Lorsque voir le code HTML n'est plus nécessaire, presser à nouveau afin d'afficher un clavier et un écran pour la saisie. Pour réinitialiser la saisie, entrer plus de 9 chiffres (la seule exception étant lors de l'Affirmation de Simon). Lorsque la saisie est effectuée, presser l'écran et le module retournera à son état initial, sonnant à nouveau si la saisie était correcte ou enregistrant une erreur et se réinitialisant si elle était incorrecte. Si elle était correcte, passer à l'étape suivante pour désamorcer le module.

Table Rase La couleur de l'écran détermine quelle version de Table Rase est rencontrée.

Si la couleur est bleue, la section utilisée est « Rien ne se passe ». Dans ce cas, diviser le nombre d'appuis en 4, en les modulo 10 chacun, l'un étant appuis + plaques de ports, appuis + piles, apuis + modules désamorcés (calculé quand le module est en mode entrée) et apouis + porte-piles. Ces nombres sont interdits dans la réponse et elle doit contenir 5 chiffres uniques des nombres valides dans n'importe quel ordre.

Si la couleur est rouge, la section utilisée est « Un son aigu se joue ». Dans ce cas, n'utiliser seulement que les colonnes et lignes 1-5 du tableau, la colonne étant le nombre d'appuis pour activer le module % 5 + 1 et la ligne étant le 2e chiffre du numéro de série % 5 + 1. Ajouter la valeur de couleur de 7 fois plus d'appuis. Les valeurs des couleurs sont 16 pour rouge, 5 pour gris, 1 pour blanc, 9 pour orange, 12 pour vert, 20 pour jaune, 32 pour violet et 64 pour bleu.

L'Affirmation de Simon (suite) Faire des couleurs de l'affirmation le nombre de porte-piles % 4 + 1 pour la gauche et le nombre de plaques de ports % 4 + 1 pour la droite (bleu 1, rouge 2, jaune 3, vert 4). Sinon, utiliser cette nouvelle couleur pour l'affirmation et répéter toutes les étapes, encore changer le nombre et encore saisir le nombre, vérifier la couleur de l'écran etc. Quand 8 nombres auront été saisis, le module ne changera pas la couleur de l'écran et soumettre sera autorisé. Si l'écran est de la bonne couleur mais que plus de nombres ont été saisis, une erreur sera enregistrée. Si les mauvais nombres sont saisis, le module n'enregistrera d'erreur que lorsque les autres nombres auront été saisis. Si plus de 8 nombres sont saisis, une erreur sera enregistrée.
