À propos de l'Affirmation de Simon

Simon grandit et a appris la logique.

Un écran affichera deux couleurs et une opération logique, ainsi qu'un Simon avec quatre boutons.

Étape 1 : Déterminer le nombre de l'étape

  • Commencer à 0.
  • Pour chaque caractère du # de série en commun avec un ind. all., ajouter 2.
  • Pour chaque type de port en double, soustraire 4.
  • Ajouter le nombre de piles, multiplié par le nombre de ports.
  • Multiplier par le nombre de l'étape.
  • Ajouter ou soustraire 25 jusqu'à arriver entre 0 et 49.

(Si le nombre est inférieur à 10, ajouter un 0. Exemple : 1 -> 01)

Étape 2 : Déterminer la couleur

  • Deux couleurs du Simon clignoteront par étape. Si une couleur clignote, la considérer comme vraie. Sinon, la considérer comme fausse.
    • Si l'affirmation de l'écran est vraie, utiliser le Tableau A.
    • Sinon, si l'affirmation est fausse, utiliser le Tableau B.
  • Presser les couleurs des étapes précédentes en y ajoutant la nouvelle couleur du tableau.

(Exemple : Pour Vrai 32, Rouge doit être pressé.)

Tableau Ops : Explication des opérateurs logiques

Connectivité logique Symbole Porte logique Signification
Conjonction ∧ ET Renvoie vrai si toutes les entrées sont vraies. Sinon renvoie faux.
Disjonction ∨ OU Renvoie vrai si une entrée est vraie. Sinon renvoie faux.
Disjonction exclusive ⊻ OU EXCLUSIF Renvoie vrai si une seule entrée est vraie. Sinon renvoie faux.
Refus alternatif | NON-ET Renvoie faux si toutes les entrées sont vraies. Sinon renvoie vrai.
Refus conjoint ↓ NON-OU Renvoie faux si une entrée est vraie. Sinon renvoie vrai.
Biconditional NON-OU EXCLUSIF Renvoie faux si une seule entrée est vraie. Sinon renvoie vrai.
Implication (Gauche) → - Renvoie faux si l’entrée gauche est vraie et que l’entrée droite est fausse. Sinon renvoie vrai.
Implication (Droite) ← - Renvoie faux si l’entrée gauche est fausse et que l’entrée droite est vraie. Sinon renvoie vrai.
