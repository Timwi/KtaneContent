À propos d'Oubliez tout

Je ne suis pas sûr de ce que c'est, mais j'ai trop peur de demander.

  • Les molettes, tubes Nixie et lumières s'actualiseront à chaque module non-ignoré résolu. L'étape actuelle est indiquée par l'écran, mais pas dans l'ordre.
  • Lors du désamorçage, remettre les étapes dans l'ordre selon l'écran en partant de 01.
  • Pour la première étape, prendre la valeur des molettes. Ceci est la solution de départ et cette étape est considérée comme valide.
  • Pour chaque étape suivante, déterminer si l'étape est valide. Si c'est le cas, se référer à la page suivante pour modifier la solution.
  • Une fois toutes les étapes affichées, l'écran des étapes, les tubes Nixie et les lumières s'éteindront. Le module est maintenant prêt à être désamorcé.
  • Entrer la solution à l'aide des molettes et tourner la clé pour désamorcer le module.
  • Ne pas interagir avec le module avant qu'il soit prêt à être désamorcé et toujours attendre que les molettes s'arrêtent avant de tourner la clé.
  • Si la réponse est incorrecte, une vérification de position libre sera accordée indiquée par la DEL à côté de l'écran des étapes.
  • Les vérifications de position peuvent être entrées en utilisant des 0 et un seul 1 pour visionner toutes les étapes concernées (par exemple, 0001000000 montre l'étape 4, 14, 24...).
  • Les vérifications de position peuvent être effectuées sans une vérification libre, mais elles enregistreront une erreur (ce qui accorde une vérification libre).
Suivre ces étapes pour déterminer si une étape est valide :
  • Si les deux étapes précédentes étaient valides, cette étape n'est pas valide.
  • Si les deux étapes précédentes n'étaient pas valides, cette étape est valide.
  • Si aucune de ces règles ne s'applique ou qu'il n'y a pas assez d'étapes précédemment, cette étape est valide si les numéros affichés sur les tubes Nixie sont sur les molettes.
Suivre ces étapes pour déterminer la couleur d'une étape :
  • Si trois couleurs sont affichées, la couleur de l'étape est celle qui n'est pas affichée.
  • Sinon, la couleur de l'étape est celle qui est affichée plusieurs fois.

  • Les chiffres de solution doivent toujours être compris entre 0 et 9 en ajoutant ou soustrayant 10.
