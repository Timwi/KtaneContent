On the Subject of Kanyeordered Keys

Law of Math: When Kanye West is multiplied by something it will always equal Kanye West.

See Appendix ORDER for identifying modules in Ordered Keys family.

SEE APPENDIX K FOR KANYE WEST ALBUM REFERENCE

This module consists of 6 keys, each of which is initially labelled with a snippet from an album cover; particularly an album by Kanye West. This module has two stages. In the first stage, the keys cannot be interacted with. When the black button is pressed, the module will transition to stage 2, where each key is colored, and a colored letter will be shown on each key. In stage 2, press the keys in a certain order and then press the black button once more to solve the module.

Stage 2

In stage 2, each key will change to bearing a color, which will be either red, green, blue, cyan, magenta, or yellow. The keys will also be labelled with a letter, which will also be colored with one of the aforementioned colors.

First, the initial values might be modified. For each key, reference Table C using the color of the key along the top, and the color of the label along the left. If the resulting square contains Kanye, subtract the initial value from 26. Otherwise, do not change the initial value.

Once the new value has been achieved, convert the letter displayed on the key to its alphabetical position (A1Z26), add the new value to the label value, and subtract 26 if the sum is not within 1-26. Then convert this number to the letter whose alphabetical position is equal to it.

Once the keys’ letters have been shifted, if at least 1 of the keys do not contain letters from “KANYE”, repeatedly increment those key’s values by 1 until they do, looping around from Z to A.
Once all the keys’ values contain a letter in “KANYE”, press all keys with the letter “K”, in any order. Then press all keys with the letter “A” in any order, repeating the process with “N”, “Y”, and “E”.
Once all valid keys have been pressed, press the black button to submit your answer.
