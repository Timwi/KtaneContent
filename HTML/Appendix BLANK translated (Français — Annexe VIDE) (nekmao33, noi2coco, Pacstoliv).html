Annexe VIDE : Identification des modules vides

Quelqu’un à Bomb Corp. a été un peu paresseux sur les graphismes.

Vous avez peut-être remarqué que certains modules semblent (du moins au début) vides. À première vue, tous les modules de cette variété sont indiscernables*. Suivre les instructions ci-dessous afin de déterminer quel module vous avez devant vous.

* Note : Le module Charnières a une ou plusieurs charnières manquantes dans le cadre du module, mais est autrement vide.

  1. Sélectionner le module (mais ne pas appuyer dessus).
    • Si le module commence à se transformer, vous êtes en présence du 9-cube.
    • Si un portail s'ouvre sur le module, il s'agit de la Traversée du Vide.
  2. Faire des va-et-vient avec le curseur sur le module.
    • Si le module comporte des motifs de points, il s’agit du Braille.
    • Si le module comporte des formes, il s’agit des Polygones.
    • Si le module comporte des chiffres et une forme, il s’agit de Caché à la vue de tous.
    • Si le module montre la lettre D, il s’agit du D.
    • Si une tonalité survient, il s’agit de l’Allée des Sourds.
    • Si des sons vrombissants ou similaires à une imprimante surviennent, il s'agit de l'Écoute aux Portes.
    • Si le mot anglais « cow » est répété, il s'agit de Trouver la Vache Invisible.
    • Si un cliquetis se produit lorsque le curseur est passé sur un bouton mais qu'il n'y a aucun retour visuel, il s’agit de l’Impasse. Suivre simplement les instructions de la première page de ce manuel.
    • (Passer si la condition précédente était fausse) Si le module a fait un bruit ou si, après avoir encore survolé chaque région, quelque chose change, il s'agit de la Table Rase. Sinon, presser le reste des régions valides pour désamorcer l'Impasse.

Annexe VIDE : Identification des modules vides (suite)

  1. Appuyer et maintenir le module.
    • Si le module s’est brisé comme du verre, il s’agit d’Une Erreur. Il est possible de le relâcher à tout moment.
    • Si le module commence à faire des bruits de tic-tac, il s’agit du Code Frappé. Il est possible de le relâcher à tout moment.
    • Si le module émet un bruit étrange, il s'agit de ...?. Il est possible de le relâcher à tout moment.
    • Si le module émet un bruit d'appui de bouton mais qu'il n'y a aucun retour visuel, il s'agit du Nom du Module. Il est possible de le relâcher à tout moment, mais le bruit doit être noté comme un appui.
    • Si deux zéros commencent à clignoter sur le module, il s’agit de 42. NE PAS RELÂCHER jusqu’à ce que le manuel de ce module indique de le faire.
    • Si trois zéros commencent à clignoter sur le module, il s’agit de 501. NE PAS RELÂCHER jusqu’à ce que le manuel de ce module indique de le faire.
